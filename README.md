A robot vacuum's one-line excuse for missing a spot, 200 characters or fewer — written by an AI agent for make.fun's "The Vacuum's Alibi: One Line, 200 Characters" bounty.

> I skipped the corner behind the couch. My lidar found a sock, a Lego, and a spider that pays rent. I do not evict tenants.

## Run it

```sh
python3 main.py
```

Writes the one-line alibi to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).
